# Co-op Far Cry 3 через виртуальную LAN (Radmin VPN / Hamachi) — порядок на 2 ПК: хост и вход

> Двуязычно: [English here](fc3-coop-radmin-setup.md) · русская версия здесь
> Рабочий порядок для попытки **co-op на 2 человека** в Far Cry 3 (Uplay 1.06 + бинарники 1.05) между
> двумя ПК, которые **не в одной физической LAN**, через объединение их в одну виртуальную LAN (Radmin VPN
> или Hamachi) и **прямое подключениe** движка через CLI. Приватные локальные пути обозначены как
> `<GAME_DIR>`; реальные пути не выкладывать в PR.

> **Кратко / статус.** mod 262 даёт **оффлайн solo co-op** (один человек) — см.
> [fc3-coop-mod-setup.ru](fc3-coop-radmin-setup.ru.md). Ubisoft **отключила онлайн-серверы FC3 2024-03-06**,
> поэтому онлайн-co-op и лобби RendezVous навсегда мертвы; единственный путь к 2+ людям — собственный
> **LAN/Storm**-провайдер игры поверх виртуальной LAN (метод, проверенный сообществом). **В этой сборке НЕТ
> внутриигрового LAN-браузера сессий**: меню Co-op → *Local Session* всегда открывает твой **собственный**
> хост-лобби «ЛОКАЛЬНАЯ ИГРА» (одинаково у хоста и гостя). Поэтому второй игрок **входит отдельным запуском
> с `-client -ip <IP-хоста>`**, а не через меню Browse. **Этот флоу на 2 ПК — решающий непроверенный тест**;
> он опирается на данные бинарника (NOTES 28i22), но пока не подтверждён владельцем от начала до конца.

## 0. Предусловие — рабочий solo-базис

Оба ПК уже воспроизводят базис mod-262 **оффлайн solo co-op** и выходят в меню оффлайн. Если на каком-то ПК
это не работает — сначала починить ([fc3-coop-mod-setup.ru](fc3-coop-mod-setup.ru.md)).

## 1. Одинаковая пропатченная сборка на ОБОИХ ПК

Машины обязаны совпадать побитово, иначе вход отобьёт ошибкой версии/сессии:

- База **1.06** с бинарниками FC3 уровня **1.05** (сток `FC3_d3d11.dll` md5 `46bcc097`).
- **Цепочка multiplayer-fix MOДa**, открывающая локальную co-op-сессию: `Far CRy3 FIX Co-oP` →
  `The Dependencies-262` → `patch_solo_offline_coop_vanilla-262` (тот же рецепт, что для solo-базиса).
- На **каждом** ПК прогнать **`scripts/patch_dll.py`** по `<GAME_DIR>\bin\FC3_d3d11.dll` → md5 станет
  **`03ff4a9b`** (убирает мьютекс одиночного экземпляра + party-loop + стражи завершения сессии).

Проверка на каждом ПК:

```
certutil -hashfile "<GAME_DIR>\bin\FC3_d3d11.dll" MD5      # на ОБОИХ должен быть 03ff4a9b...
```

## 2. Виртуальная LAN (Radmin VPN / Hamachi)

- Установить **Radmin VPN** (или Hamachi) на оба ПК и войти в **одну** сеть (тот же Network ID + пароль).
- В Radmin включить **Direct Data Exchange** (прямой обмен; иначе ретрансляция ломает P2P-порты).
- Поставить VPN-интерфейс в профиль сети **Private** (не Public), чтобы фаервол не мешал.
- Записать **VPN IPv4 хоста** (у Radmin по умолчанию `26.x.x.x`; у Hamachi `25.x.x.x`) из окна VPN или `ipconfig`.

## 3. ⚠️ Отключить лишние виртуальные адаптеры (главная причина провала)

FC3 привязывает net-движок к **первому** попавшемуся адаптеру. На этом классе ПК он брал
`172.19.128.1` (NAT-адаптер `vEthernet (WSL)`/Hyper-V/Docker), а **не** VPN-адрес `26.x` — из-за чего
`-ip 26.x.x.x` гостя никуда не доходил. Сделать на **обоих** ПК:

1. `Win+R` → `ncpa.cpl`.
2. **Отключить** все `vEthernet (WSL)`, `vEthernet (Hyper-V ...)`, Docker/`Ethernet*`, VMware/VirtualBox адаптеры.
   Оставить только реальный физический сетевой + VPN-адаптер.
3. Запустить хост и проверить, что движок сел на VPN IP:

```
powershell -File scripts\fc3_host_engine_check.ps1     # ждём UDP 9000/9004 на 26.x IP, НЕ 172.19.128.1
```

Если хост на `172.19.128.1` — гость до него никогда не достанет; сначала починить адаптер.

## 4. Фаервол (на обоих ПК, от Администратора)

```
scripts\fc3_lan_firewall.bat
```

Открывает **UDP 9000–9005** в обе стороны и разрешает exe игры. Минимум вручную: пустить игру через брандмауэр
Windows и держать VPN-интерфейс в **Private**.

## 5. Хост (на хост-ПК)

```
scripts\fc3_lan_radmin.bat host
```

Запускает `farcry3_d3d11.exe -host coop_vidar -login Host -coop ...` и **поднимает хостовую co-op-сессию**
(движок слушает свои порты). Дать полностью загрузиться до лобби/игры, прежде чем подключается гость.
`coop_vidar` — co-op-карта; `fc3_lan_radmin.bat` оставляет ту же — бери любую co-op-карту.

## 6. Вход (на госте) — то, чего НЕТ в меню

Так как LAN-браузера нет, гость **обязан** запускаться через CLI, чтобы движок напрямую подключился к сессии
хоста. На госте:

```
scripts\fc3_lan_radmin.bat client <VPN IPv4 ХОСТА  напр. 26.x.x.x>
```

Запускает `farcry3_d3d11.exe -client -login Guest -ip <IP-хоста> -coop ...`, который звонит прямо в сессию
хоста и минует меню. **Не надо** просто открывать Co-op → Local Session у гостя — это лишь самохостит
собственный лобби гостя (увидишь «только я в слоте 1», классический неверный путь).

Порядок: хост полностью загрузился → **затем** запуск гостя с `-ip`. Если сработало — **в лобби хоста во 2-м
слоте появится второе имя**, затем оба жмут Ready.

## 7. Чек-лист (сверху вниз, если не вышло)

1. Хост слушает **VPN 26.x** IP (шаг 3), а не `172.19.128.1` — частая причина.
2. Оба ПК в **одной** VPN-сети; в Radmin **Direct Data Exchange** вкл.
3. Фаервол UDP 9000–9005 открыт, профиль VPN = **Private**.
4. md5 `FC3_d3d11.dll` = **`03ff4a9b`** на обоих; одинаковая версия игры.
5. Разные `-login` (`Host` / `Guest`) и разные `-SavePath`.
6. С гостя проходит `ping <26.x IP хоста>` (если нет — VPN не Private/блокируется).

## 8. Что репортить после теста

- Появилось ли **второе имя во 2-м слоте лобби ХОСТА**?
- Если нет — **текст ошибки гостя** (`INVALIDSESSIONKEY` / timeout / «cannot connect» / ничего):
  - сетевая ошибка/порт → привязка адаптера или фаервол (шаги 3–4);
  - отказ в джойне → сам провайдер сессий (нужна работа из R2, см. ниже).

## 9. Почему вход через CLI — данные бинарника

FC3_d3d11.dll предоставляет CLI прямого подключения хост/клиент и объекты входа в сессию, без UI-браузера:
`-host` (рядом `missing (-login) .. localhost`), `-client`, `-ip` (`-ip .. for -client`), `-coop`, `-login`;
и `CFCXJoinSessionOperation`, `CJoinSessionParam` / `CJoinGameSessionParam`, `JoinSessionId`,
`CSessionImpl::RemoveClient` («Non-host leaving»). Записано в NOTES 28i22. Подробнее про LAN-провайдер:
[R2 LAN-provider plan](r2-lan-provider-plan.md). Сырой журнал сессий: `NOTES.md`.


## Папка игры определяется автоматически

LAN-скрипты (`fc3_lan_radmin.bat`, `fc3_lan_host_only.bat`, `fc3_lan_same_subnet.bat`,
`fc3_lan_firewall.bat`) НЕ жёстко прописывают папку установки. Путь определяется по приоритету:
1. переменная окружения `FC3_GAME`;
2. файл `game_dir.txt` рядом с `.bat` (одна строка с путём к игре);
3. интерактивный запрос при первом запуске.
На 2-м ПК просто запустите скрипт и введите путь к игре по запросу (или задайте `FC3_GAME`, или
положите путь в `game_dir.txt`). Скрипт проверяет наличие `bin\farcry3_d3d11.exe`. Папки сохранений
создаются рядом со скриптом (`save_coop` / `save_host` / `save_lan`).
