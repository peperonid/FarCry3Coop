# OW15 Open World Co-op — чек-лист онлайна на 2 игроков (ЦЕЛЬ 1)

Как играть в co-op Far Cry 3 с другом ОНЛАЙН (без проброса портов) с помощью мода
«Far Cry 3 Open World Co-op (Patch 1.5)» (пак `H:\FarCryCoop\Downloads\OW15`, архив
`Far Cry 3 Open World Co-op (Patch 1.5)-220-1-5-...zip`, 2.7 ГБ).

Этот путь требует живой Ubisoft Connect. Мультиплеер OW15 идёт через co-op-сессии самого
Ubisoft, которые ретранслируются серверами Ubisoft, поэтому проброс портов НЕ нужен.
(Для полностью ОФЛАЙН co-op этот мод НЕ работает — это отдельная нерешённая цель.)

## 0. Что такое OW15 и чем он не является
- ЭТО хост/клиентский мультиплеер co-op через Ubisoft-онлайн (в changelog readme: «хост больше не вылетает, когда у КЛИЕНТОВ packet loss»).
- Это НЕ офлайн. Нужен Ubisoft Connect залогиненный + онлайн.
- Он ЗАМЕНЯЕТ мир: «пока мод стоит, нельзя играть соло и в ванильные co-op карты». Сначала сделай резервную копию.
- Схема игры (readme): создать ПРИВАТНУЮ co-op-сессию из главного меню, поставить главу ROOK ISLANDS (или fc3_main).

## 1. Версия базы (главная ловушка) — 1.04/1.05, НЕ 1.06
- OW15 (и mod-262) сделаны для **1.04/1.05** FC3, в `bin\` которой используются
  `uplay_r1_loader.dll` + `ubiorbitapi_r2_loader.dll` (пак OW15 их приносит с собой).
- Настоящая **1.06**-установка использует вместо них `upc_r1_loader.dll` и с модом НЕ совпадёт.
- `FC3_d3d11.dll` пака (md5 `07abaf66`, 30 057 832 байта) — это бинарь эпохи 1.05.
- Действие: начинай с чистой **1.04/1.05** установки FC3. На ОБОИХ ПК — ОДИНАКОВАя версия базы.
- НЕ переиспользуй экспериментальную копию этого репо `H:\FarCryCoop\TestFC3_105` — там офлайн-загрузчик
  от mod-262, это не чистая база для OW15.

## 2. На каждом ПК игрока (сделать на ОБОИХ)
1. Сначала сделай резервную копию чистой папки FC3 (OW15 перезаписывает много файлов).
2. Начинай с чистой 1.04/1.05 установки FC3 (проверенной/установленной через Ubisoft Connect).
3. Убедись, что НЕТ других co-op-модов (ни mod-262, ни Open World 1.0, ни прокси/офлайн-загрузчика). В `bin\` — только оригинальные файлы базы, ничего кастомного.
4. Скопируй папку «Far Cry 3» из распакованного патча OW15 ПОВЕРХ папки установки игры (шаг readme). Если Ubisoft Connect потом перезапишет файлы — снова скопируй OW15 после любой «проверки/восстановления».
5. Установи Ubisoft Connect, войди со СВОЕГО аккаунта Ubisoft (каждому игроку нужна СВОЯ лицензионная FC3 + свой аккаунт; общий аккаунт — нет).

## 3. Запуск
- Запускай игру обычным способом через Ubisoft Connect (онлайн). Никаких офлайн/прокси-загрузчиков.
- Убедись, что у Ubisoft Connect есть интернет и файрвол его пропускает (и игру). Игровой порт пробрасывать не нужно (Ubisoft ретранслирует co-op).

## 4. Хост (игрок 1)
1. Главное меню -> Co-op -> Создать игру -> сделать её ПРИВАТНОЙ.
2. Поставь главу **ROOK ISLANDS** (EN) или **fc3_main** (если по языку видно такое имя).
3. Дождись загрузки сессии/мира, пока не окажешься в открытом мире.

## 5. Клиент (игрок 2)
1. В Ubisoft Connect (оверлей) заранее добавьте друг друга в друзья.
2. Присоединись к приватной сессии хоста через список друзей Ubisoft («Присоединиться к игре») или прими приглашение хоста.
3. Когда спросят миссию/главу — выбери ТО ЖЕ, что у хоста (ROOK ISLANDS / fc3_main).

## 6. Проверка работоспособности (то, что просит подтвердить задача)
Оба игрока одновременно в ОДНОМ открытом мире и всё синхронно:
- [ ] Видно, как персонажи двигаются в реальном времени.
- [ ] Оба могут стрелять/ездить; никого не выкидывает.
- [ ] При большом расстоянии друг от друга связь не рвётся (это и есть доказательство работы без проброса портов через relay Ubisoft).
- [ ] Если один умирает, второй может его поднять / сессия не завершается.
- [ ] Реконнект клиента работает (переприсоединение).

## 7. Устранение неполадок
- Игра не стартует / «другой экземпляр»: залипший лок — перезагрузка или снять процесс; НЕ смешивай патч мульти-экземплярности mod-262 с OW15.
- «Серверы недоступны» / нельзя создать сессию: Ubisoft Connect не залогинен / офлайн, либо неверная версия базы, либо файлы OW15 перезаписаны проверкой (снова скопируй OW15).
- Один игрок не может войти: несовпадение версий на двух ПК, несовпадение под-версии OW15, или вас нет в друзьях Ubisoft. Сделай оба ПК идентичными (та же база + тот же OW15 1.5).
- Антивирус/Defender блокирует Ubisoft Connect: разреши.
- Число игроков: в ванили FC3 co-op = 2; этот чек-лист на 2. Если нужно 3-4 — проверь на странице мода, поддерживает ли OW15 Patch 1.5 больше 2; не предполагай это.

## 8. Важные честные замечания
- Пак OW15 кладёт тот же офлайн uplay-загрузчик, что у mod-262, но мультиплеер OW15 всё равно
  требует живых серверов Ubisoft (подтверждено владельцем). Считай мод ОНЛАЙН--only.
- Если целью позже станет полностью ОФЛАЙН co-op, OW15 не поможет; для этого нужна локальная
  эмуляция RendezVous/auth, отслеживаемая отдельно (см. NOTES 28cw-28dl).
