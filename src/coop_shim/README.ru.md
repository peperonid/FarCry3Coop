# coop_shim - шим установления сессии пути B (КАРКАС)

**Статус: КАРКАС, не тестировался, НЕ развёрнут, НЕ записан в игру.** Это проектный каркас плана офлайн-кооперации
кампании в [`docs/coop-online-routes.md`](../../docs/coop-online-routes.md) (путь B), опирающийся на реверс из `NOTES.md` 28r-28ad.
Сборка `build_x86.bat` (x86) даёт `coop_shim.dll` только здесь.

## Что делает (замысел)
Установление сессии кооперации кампании Far Cry 3 целиком привязано к RendezVous (NOTES 28ac/28ad): гейт `FUN_11279ba0`
требует флаг онлайна (`FUN_11245090`) и RV `SandboxUrl` (`FUN_112492a0`), а обработчики, в которые он выпускает, - RV-сервисы
(хост -> SubAccountClient `FUN_11275d90`, вход -> UbiAuthentication `FUN_1127a1d0`). `SessionTicket` - только MD5 (NOTES 28z).
Шим перенаправляет этот путь в локальную LAN-сессию `storm::echo`:

| Точка (RVA) | Оригинал | Замысел шима |
|---|---|---|
| `online_flag` `FUN_11245090` | читает флаг включения онлайна | вернуть 1 |
| `rv_sandboxurl` `FUN_112492a0` | RV net-op, нужен `SandboxUrl` | подставить LAN-адрес, вернуть 1 |
| `gate` `FUN_11279ba0` | RV-гейт, out = адрес+порт | успех с LAN-адресом+портом |
| `host_handler` `FUN_11275d90` | сессия `SubAccountClient` | `CFCXCreateSessionOperation` (`NetEngineType=LAN`) |
| `join_handler` `FUN_1127a1d0` | UbiAuthentication | `CFCXJoinSessionOperation` на LAN-адрес |
| `ticket_validate` `FUN_11254be0` | MD5 validate | принять локально выведенный MD5-тикет |
| `ticket_prepare` `FUN_1124e5e0` | сеть AcquireTicket | пропустить сеть, подать локальный тикет |

MD5 реализован локально (асимметричной крипто нигде нет); оба пира с одинаковым шимом выводят один ключ.

## Уточнение 28af (ABI конкретизирован)
- Флаг онлайна = глобал `DAT_11f07e48` (RVA `0x1f07e48`); каркас пишет 1 на старте (хук тоже оставлен).
- Out-структура гейта = `sockaddr_in`: family@+0 (AF_INET=2), port@+2 (сеть), IPv4@+4 (сеть) - NOTES 28af. `hk_gate` строит это (htons/htonl).
- Добавлен хук `rv_connected` (`FUN_11237670` -> 1), требуемый AcquireTicket + билдером тикета.
- `derive_local_ticket` пока хеширует только `FC3COOP_SECRET`; точные общие поля (id сессии / playlist / account, NOTES 28aa) нужен живой прогон.

## Чеклист рантайм-теста (на стороне владельца; агент не может подключиться - FC3 блокирует инъекцию)
1. Сборка: `build_x86.bat` -> `coop_shim.dll` (x86).
2. Загрузить в рабочую копию `H:\FarCryCoop\TestFC3_105\` (НЕ в реальную установку): перехват порядка загрузки DLL либо существующий
   `src/uplay_proxy` лоадер вызывает `init()` шима (он уже в пути загрузки).
3. Перед запуском задать env: `FC3COOP_SHIM=1`, `FC3COOP_SECRET=<одинаковый у всех пиров>`, (TODO) IP/порт хоста.
4. Запустить 2 инстанса (см. `scripts/fc3_lan_coop_launch.bat`). Смотреть `OutputDebugString` (DebugView) на строки `shim:`:
   `online global ...=1`, `gate -> success (LAN ...)`, `host -> CFCXCreate...`, `join -> CFCXJoin...`, `ticket_validate -> accept`.
5. Признак успеха: сессия кооперации формируется БЕЗ "service unavailable"/ошибки тикета, и оба клиента в одном мире.
6. Краш на хуке => у этой точки неверные сохранённые байты/соглашение вызова (TODO трамплина): перезапустить дизасембл этого RVA и править.
