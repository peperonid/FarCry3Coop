# Запуск `coop_shim` на тестовой копии - пошагово (NOTES 28ah)

**Что этот прогон из себя представляет (прочитать сначала).** Каркас из `src/coop_shim/` собирается и, если включён, патчит 8 функций игры
и принудительно ставит глобал онлайна. Но это по-прежнему **smoke-тест**, а не рабочий кооператив: сохранённые байты/трамплины по хукам
лежат в одном общем слоте (см. TODO в `patch_5`/`install_hooks`), а хук-заглушки не вызывают оригинал, поэтому хук с несовпадением
соглашения вызова (thiscall/fastcall против cdecl заглушки) может испортить стек. Ждите **данные** (загружается ли, печатаются ли строки
`shim:`, где падает), а не готовую сессию. Именно эти данные и закрывают оставшиеся TODO.

Безопасность: работать только с копией `H:/FarCryCoop/TestFC3_105`. Реальную установку `H:/Uplay/Far Cry 3` не трогать (по правилу только чтение).

---

## 0. Предварительно
- Visual Studio 18 (любая Community) доступна через `vcvars32` (x86). Скрипт сборки сам её вызывает.
- Тестовая копия в `H:/FarCryCoop/TestFC3_105`, прокси-загрузчик уже стоит в `.../bin/uplay_r1_loader.dll`
  (ABI-починенный прокси; настоящий загрузчик Ubisoft лежит в `.../bin/real/`).
- **DebugView** (Sysinternals `dbgview.exe`) - `coop_shim` пишет через `OutputDebugStringA`, DebugView видит это без отладчика.
- Опционально: второй ПК в той же LAN для честного теста входа (иначе loopback + тюнинг, см. шаг 7).

## 1. Собрать DLL шима
```
cd src/coop_shim
build_x86.bat        -> на выходе coop_shim.dll   (ожидать: BUILD_DONE 0)
```

## 2. Заставить игру загрузить шим (одноразовый хук в прокси)
Никто не импортирует `coop_shim.dll`, значит его должен загрузить через `LoadLibrary` кто-то, кто уже в пути загрузки. Этот кто-то - прокси.
Добавьте **ленивую, безопасную по loader-lock** однократную загрузку в `src/uplay_proxy/uplay_proxy.cpp`: НЕ в `DllMain` (loader lock),
а при первом UPLAY-экспорте:
```c
// рядом с остальными глобалами:
static LONG g_shim_loaded = 0;
static void tryLoadShim(void) {
    if (InterlockedCompareExchange(&g_shim_loaded, 1, 0) == 0) {
        LoadLibraryA("coop_shim.dll");   // рядом с uplay_r1_loader.dll в bin/
    }
}
```
Вызовите `tryLoadShim();` в начале трampoline-а `UPLAY_Init` (`th_20`). Затем пересоберите прокси (`build_x86.bat`/`build.bat` в
`src/uplay_proxy`) и задеплойте в `.../bin/uplay_r1_loader.dll`. (Можно попросить агента это прописать и собрать.)

## 3. Развернуть
- Скопировать `coop_shim.dll` в `H:/FarCryCoop/TestFC3_105/bin/` (тот же каталог, что `uplay_r1_loader.dll`).
- Откат = удалить этот `coop_shim.dll`; кооп-фейк прокси по умолчанию ВЫКЛ, поэтому игра работает как обычно.

## 4. Окружение (задавать в ТОМ ЖЕ окне, что запускает игру)
```
set FC3COOP_SHIM=1
set FC3COOP_SECRET=одинаковыйДляВсехПиров
```
`FC3COOP_SHIM` должен быть ровно `1`, иначе шим загрузится инативным. `FC3COOP_SECRET` обязан совпадать у всех пиров (затравка локального MD5-тикета).

## 5. Включить захват лога
- Запустить **DebugView от администратора**, Options -> включить **Capture Win32** и **Capture Global Win32**, Edit -> Filter/include `shim:`.
- Не закрывать DebugView весь прогон.

## 6. Smoke-тест (один инстанс) - начать с этого
1. `H:/FarCryCoop/TestFC3_105/bin/farcry3.exe` (обычный запуск, соло).
2. В DebugView ожидать по порядку:
   - `shim: FC3_d3d11 base=0x... enable=1`
   - `shim: online global DAT_11f07e48=1`
   - восемь строк `shim: patch <имя> @0x...`, затем `shim: hooks installed (SCAFFOLD - untested)`
3. Дойти до главного меню. **Если игра дошла до меню с этими строками - патчи встали без краша на старте**, база хороша.
4. Попробовать **создать (Host)** кооп-сессию. Следить, какой хук сработает (`shim: host -> ...`) и будет ли краш. Краш здесь - *полезные данные*:
   запишите модуль+смещение сбоя (диалог об ошибке игры или `.dmp`), чтобы починить соглашение вызова конкретно этого хука.

## 7. Тест входа на двух инстансах (после успешного smoke)
- На одном ПК нужен ещё и loopback-тюнинг echo в конфиге игры (НЕ в командной строке): `LanMatchmakingDiscoveryOnLoopbackEnable=1`,
  `LanMatchmakingReuseAddress=1` и опция "LAN Match Making Port". Затем:
```
scripts/fc3_lan_coop_launch.bat        (сначала host, дождаться мира, затем клиент -ip 127.0.0.1)
```
- На двух ПК: у клиента указывать **LAN-IP хоста** вместо `127.0.0.1`; держать `FC3COOP_SECRET` одинаковым на обоих.

## 8. Записать и вернуть (ради этого и прогон)
Собрать и прислать:
- полный хвост лога `shim:`;
- при краше: **модуль + смещение** сбоя и какая строка `shim: ...` напечаталась последней (укажет, какой хук/соглашение чинить);
- при попытке входа: загрузился ли мир или выскочила ошибка, любой текст `Ticket`/`INVALIDSESSIONKEY`/`GameSessionKey`.
Это закрывает четыре рантайм-Only TODO из NOTES 28ah: место записи `NetEngineType`/`SearchIdAddress`, трамплины/соглашения вызова по хукам,
«формируется ли нативная LAN storm::echo-опа после закорачивания RV-авторизации» и набор общих полей тикета.

## 9. Откат
Удалить `bin/coop_shim.dll` и (если добавляли) правку `tryLoadShim` в прокси - игра снова обычная.
